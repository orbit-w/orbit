# Orbit 内部依赖库 (lib)

本目录包含 Orbit 项目的内部依赖工具和模块，为项目提供核心功能支持。

## 目录结构

```
lib/
├── base/           # 基础功能模块
├── module/         # 核心业务模块
└── utils/          # 工具函数库
```

## 模块说明

### base/ - 基础功能模块

#### protoid/
- **功能**: 协议 ID 生成和管理
- **主要文件**: `protoid.go`
- **核心功能**:
  - 基于 MurmurHash3 算法生成协议消息的哈希 ID
  - 支持批量生成和缓存机制
  - 提供消息名称解析功能
- **使用场景**: 网络协议消息路由和识别

### module/ - 核心业务模块

#### db/mgo_builder/
- **功能**: MongoDB 操作构建器和对象池
- **主要文件**: 
  - `mongo_update_builder.go` - MongoDB 更新操作构建器
  - `pool.go` - 对象池管理
  - `update_fields.go` - 字段更新操作
- **核心功能**:
  - 提供类型安全的 MongoDB 更新操作构建
  - 对象池模式减少 GC 压力
  - 支持自动生命周期管理
- **使用场景**: 数据库操作优化和性能提升

#### dirty/
- **功能**: 脏标记跟踪系统
- **子模块**:
  - `dirty_tracker/` - 基础脏标记追踪器
  - `xmap/` - 细粒度 Map 变更跟踪
- **核心功能**:
  - 支持嵌套脏标记传播
  - 细粒度 Map 字段变更跟踪
  - 回调机制支持变更通知
  - 非线程安全设计，极致性能
- **使用场景**: 数据变更检测和增量更新

#### logger/
- **功能**: 日志管理模块
- **主要文件**: `logger.go`
- **核心功能**:
  - 基于 meteor 框架的日志系统
  - 支持文件轮转和格式化
  - 提供全局日志实例管理
- **使用场景**: 应用日志记录和调试

#### unipue_task_exec/
- **功能**: 唯一任务执行器
- **主要文件**: 
  - `unique_task_executor.go` - 任务执行器
  - `task_runner.go` - 任务运行器
- **核心功能**:
  - 确保相同 key 的任务只执行一次
  - 支持并发等待和上下文控制
  - 异常处理和恢复机制
- **使用场景**: 防止重复任务执行，提高系统效率

### utils/ - 工具函数库

#### murmur3/
- **功能**: MurmurHash3 哈希算法实现
- **主要文件**: `murmur3.go`, `murmur3_test.go`
- **核心功能**:
  - 32位和128位 MurmurHash3 实现
  - 支持 x86 和 x64 架构优化
  - 提供字符串哈希便捷函数
- **使用场景**: 高性能哈希计算

#### proto_utils/
- **功能**: Protocol Buffers 相关工具
- **主要文件**: `proto.go`
- **核心功能**:
  - 消息名称解析和提取
  - 类型反射处理
  - 支持指针和匿名结构体
- **使用场景**: Protocol Buffers 消息处理

#### proto_hash.go
- **功能**: Protocol Buffers 消息哈希工具
- **核心功能**:
  - 与 `base/protoid` 功能重复，提供统一接口
  - 支持批量哈希生成
  - 消息名称解析功能
- **使用场景**: 协议消息 ID 生成

## 设计特点

1. **高性能**: 采用对象池、非线程安全设计等优化手段
2. **模块化**: 清晰的模块划分，职责单一
3. **类型安全**: 充分利用 Go 泛型特性
4. **内存友好**: 对象复用和自动生命周期管理
5. **扩展性**: 支持嵌套和回调机制

## 使用建议

1. **对象池使用**: 优先使用 `WithBuilder` 和 `WithTracker` 等自动管理函数
2. **脏标记**: 在需要变更检测的场景使用，注意非线程安全特性
3. **任务执行**: 使用唯一任务执行器避免重复计算
4. **哈希计算**: 根据数据大小选择合适的哈希算法变体

## 注意事项

- 大部分模块设计为非线程安全，使用时需要外部同步
- 对象池中的对象使用后需要及时归还
- 脏标记系统支持嵌套，注意父子关系的正确设置
- 日志系统基于 meteor 框架，需要正确初始化
