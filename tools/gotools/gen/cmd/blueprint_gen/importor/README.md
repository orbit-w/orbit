# Import 生成器 (Importor)

## 概述

`importor` 是一个用于 Go 代码生成工具的 import 管理器，专门为 `router_gen` 工具设计。它能够：

1. 从现有 Go 文件中提取 import 语句
2. 添加新的 proto 包 import
3. 按照标准格式对 imports 进行分组和排序
4. 生成格式化的 import 代码块

## 功能特性

### 1. Import 提取
从现有的 Go 文件中提取所有 import 语句，包括别名。

### 2. Import 分组
自动将 imports 分为四组：
- **标准库**: `fmt`, `strings` 等
- **第三方库**: `github.com/*`, `gitee.com/*` 等
- **本地项目包**: 项目内部的包（不包括 proto）
- **Proto 包**: `pkg/proto/*` 和 `google.golang.org/protobuf/proto`

### 3. 自动排序
每个分组内的 imports 按字母顺序排序。

### 4. 智能合并
合并现有 imports 和新添加的 imports，避免重复。

## 使用方法

### 基本用法

```go
package main

import (
    "fmt"
    "gitee.com/orbit-w/orbit/tools/gotools/gen/cmd/blueprint_gen/importor"
)

func main() {
    // 1. 创建 import 管理器
    mgr := importor.NewImportManager("gitee.com/orbit-w/orbit")
    
    // 2. 从现有文件中提取 imports（如果文件存在）
    if err := mgr.ExtractFromFile("path/to/controller.go"); err != nil {
        panic(err)
    }
    
    // 3. 添加需要的 proto 包
    mgr.AddProtoPackage("core")
    mgr.AddProtoPackage("mme")
    mgr.AddProtoPackage("sample")
    
    // 4. 确保必需的 imports 存在
    mgr.EnsureImport("gitee.com/orbit-w/orbit/internal/game/mme", "mmeobj")
    
    // 5. 生成 import 代码块
    imports := mgr.Generate()
    
    // 6. 使用生成的 imports
    fmt.Printf("import (\n%s)\n", imports)
}
```

### 在 router_gen 中使用

#### 示例 1: 生成 Controller 文件的 imports

```go
func generateControllerFile(ctx *RouterGenContext) (string, error) {
    var code strings.Builder
    
    // 文件头和 package 声明
    code.WriteString("// Code generated by routergen. DO NOT EDIT.\n")
    code.WriteString(fmt.Sprintf("package %s\n\n", ctx.Controller.PackageName))
    
    // 使用 ImportManager 生成 imports
    mgr := importor.NewImportManager("gitee.com/orbit-w/orbit")
    
    // 提取现有 imports（如果文件存在）
    if ctx.ControllerPath != "" {
        mgr.ExtractFromFile(ctx.ControllerPath)
    }
    
    // 添加所有需要的 proto 包
    for _, req := range ctx.Requests {
        mgr.AddProtoPackage(req.PackageName)
    }
    
    // 确保必需的包存在
    mgr.EnsureImport("gitee.com/orbit-w/orbit/internal/game/mme", "mmeobj")
    
    // 生成 import 块
    code.WriteString("import (\n")
    code.WriteString(mgr.Generate())
    code.WriteString(")\n\n")
    
    // ... 生成其他代码 ...
    
    return code.String(), nil
}
```

#### 示例 2: 增量更新 imports

```go
func appendNewMethodsWithImports(ctx *RouterGenContext, controllerPath string) error {
    // 检查是否需要添加新的 imports
    mgr := importor.NewImportManager("gitee.com/orbit-w/orbit")
    mgr.ExtractFromFile(controllerPath)
    
    // 检查新方法需要的 proto 包
    for _, req := range ctx.NewRequests {
        if !mgr.HasImport(fmt.Sprintf("gitee.com/orbit-w/orbit/pkg/proto/%s", req.PackageName)) {
            mgr.AddProtoPackage(req.PackageName)
        }
    }
    
    // 检查是否需要 mmeobj
    needsMMEObj := false
    for _, req := range ctx.NewRequests {
        if len(req.EntityRefs) > 0 {
            needsMMEObj = true
            break
        }
    }
    
    if needsMMEObj && !mgr.HasImport("gitee.com/orbit-w/orbit/internal/game/mme") {
        mgr.EnsureImport("gitee.com/orbit-w/orbit/internal/game/mme", "mmeobj")
        // 在文件中插入新的 import...
    }
    
    // ... 继续处理 ...
}
```

## API 文档

### ImportManager

#### 创建实例

```go
func NewImportManager(projectPrefix string) *ImportManager
```

创建一个新的 import 管理器。

**参数:**
- `projectPrefix`: 项目前缀，用于识别本地包（例如: `"gitee.com/orbit-w/orbit"`）

#### 方法

##### ExtractFromFile

```go
func (im *ImportManager) ExtractFromFile(filePath string) error
```

从 Go 文件中提取现有的 import 语句。

**参数:**
- `filePath`: Go 文件路径

**返回:**
- `error`: 如果解析失败返回错误，文件不存在不算错误

##### AddProtoPackage

```go
func (im *ImportManager) AddProtoPackage(packageName string)
```

添加一个 proto 包。

**参数:**
- `packageName`: proto 包名（例如: `"core"`, `"mme"`）

##### AddProtoPackages

```go
func (im *ImportManager) AddProtoPackages(packages []string)
```

批量添加 proto 包。

**参数:**
- `packages`: proto 包名列表

##### EnsureImport

```go
func (im *ImportManager) EnsureImport(path, alias string)
```

确保某个 import 存在。如果已存在，不会覆盖。

**参数:**
- `path`: import 路径
- `alias`: 别名（如果不需要别名，传空字符串）

##### Generate

```go
func (im *ImportManager) Generate() string
```

生成格式化的 import 代码块（不包括 `import (` 和 `)`）。

**返回:**
- `string`: 格式化的 import 代码

##### HasImport

```go
func (im *ImportManager) HasImport(path string) bool
```

检查是否已存在某个 import。

**参数:**
- `path`: import 路径

**返回:**
- `bool`: 如果存在返回 true

##### GetImportAlias

```go
func (im *ImportManager) GetImportAlias(path string) (string, bool)
```

获取 import 的别名。

**参数:**
- `path`: import 路径

**返回:**
- `string`: 别名（如果没有别名返回空字符串）
- `bool`: 如果 import 存在返回 true

## 设计原则

1. **增量友好**: 支持从现有文件提取 imports，避免覆盖用户手动添加的 imports
2. **智能分组**: 自动按照 Go 社区标准对 imports 进行分组
3. **避免重复**: 自动去重，确保每个 import 只出现一次
4. **保留别名**: 保留现有 imports 的别名
5. **自动排序**: 每个分组内自动排序，保持代码整洁

## 集成到现有代码

### 替换 controller_gen.go 中的 import 生成逻辑

可以用 `ImportManager` 替换以下函数：
- `extractExistingImports()`
- `mergeAndGroupImports()`

示例：

```go
// 旧代码
existingImports := extractExistingImports(ctx)
allImports := mergeAndGroupImports(existingImports, protoPackages, ctx)

// 新代码
mgr := importor.NewImportManager("gitee.com/orbit-w/orbit")
mgr.ExtractFromFile(ctx.ControllerPath)
for pkgName := range protoPackages {
    mgr.AddProtoPackage(pkgName)
}
mgr.EnsureImport("gitee.com/orbit-w/orbit/internal/game/mme", "mmeobj")
allImports := mgr.Generate()
```

## 注意事项

1. 项目前缀必须正确设置，用于区分本地包和第三方包
2. Proto 包会自动添加 `google.golang.org/protobuf/proto`
3. 已存在的 imports 不会被 `EnsureImport` 覆盖
4. 文件不存在时 `ExtractFromFile` 不会报错，会返回空的 imports
